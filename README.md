# QualiQ

資格・検定の練習問題を解いて学習する Web アプリです。`index.html` 1 ファイルで動き、ビルドは不要です。

## 主な機能

- **収録検定**（各20問のオリジナル練習問題）
  - IT：ITパスポート・基本情報・応用情報
  - 語学：英検・TOEIC
  - ビジネス・法律：日商簿記・FP・宅建
  - 教養：漢検（**4級・3級・準2級・2級** を選んで演習）
  - 農業・測量・技術：**測量士補・測量士**、**日本農業技術検定 3級・2級**
  - 級・区分のある検定は、カードのプルダウンで級を選びます。選んだ級はブラウザに記憶されます
  - 実際の試験問題・過去問ではありません。制度や出題範囲は各試験の公式情報で確認してください。
- **演習**
  - 検定別・全検定ミックス・カテゴリ別ミックス（1回最大20問、選択肢は毎回シャッフル）
  - 解答モード：まとめて採点 / 一問ずつ答え合わせ
  - 途中で中断しても「続きから再開」できます（リロードしても再開されます）
- **復習**：今日の復習（間隔反復）・間違えた問題・ブックマーク・苦手分析（分野別 / 検定別）
- **自作検定**：最大100問。CSV・タブ区切り（Excel から貼り付け）・JSON から一括で取り込めます
- **成績**：検定ごとの合格ライン（目安）、推移グラフ、検定での絞り込み
- **その他**：学習目標の管理、ダークモード、キーボード操作（`1`〜`4` / `Enter` / `←` `→` / `B` / `Esc`）

## 使い方

リポジトリのファイルをそのまま GitHub Pages などの静的ホスティングで公開します。`index.html` をブラウザで直接開いても動きます。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | 画面の HTML |
| `js/data/exams.js` | 収録検定と問題データ（問題の追加・修正はここ）。級・区分のある検定は `group` が同じ項目として並べると1枚のカードにまとまります |
| `js/app.js` | アプリ本体（保存、演習、復習、自作検定など） |
| `js/theme-init.js` | 画面描画前にダークモードを適用する小さなスクリプト |
| `css/tailwind.css` | Tailwind CSS の生成物（**直接編集しない**） |
| `css/app.css` | 独自のスタイル（ダークモードなど） |
| `src/tailwind.css` / `tailwind.config.js` | Tailwind の入力ファイルと設定 |
| `firestore.rules` | Firestore のセキュリティルール |

## データの保存先

| 状態 | 保存先 | 右上の表示 |
|---|---|---|
| Firebase に接続できたとき | Cloud Firestore（匿名認証で利用者ごとに分離） | クラウド同期中 |
| 接続できないとき | このブラウザの localStorage | この端末に保存 |
| ブラウザの保存領域が使えないとき | メモリのみ（再読み込みで消えます） | 一時保存のみ |

お問い合わせフォームの内容は Firestore の `artifacts/kentei-exam-app/contacts` に保存されます（Firebase コンソールで確認します。通知はされません）。

## Firebase の設定

1. Authentication → ログイン方法で「匿名」を有効にする
2. Firestore Database を作成し、ルールに [`firestore.rules`](firestore.rules) の内容を貼り付けて公開する
3. Authentication → 設定 → 承認済みドメインに公開先のドメインを追加する（例：`<ユーザー名>.github.io`）

Web 用の Firebase 設定値（`apiKey` など）は公開される前提の識別子です。アクセス制御は Firestore のセキュリティルールで行います。

## 自作検定の取り込み形式

CSV（1行1問）：

```
問題文,選択肢ア,選択肢イ,選択肢ウ,選択肢エ,正解,解説
日本の首都はどこか。,東京,大阪,京都,名古屋,ア,1868年に東京へ遷都しました。
```

- 正解は `ア`〜`エ`、`A`〜`D`、`1`〜`4`、または正解の選択肢の文字で指定できます
- 解説は省略できます。1行目が見出しなら自動で読み飛ばします
- Excel やスプレッドシートの表を貼り付けた場合（タブ区切り）も読み込めます

JSON：

```json
[
  { "question": "日本の首都はどこか。", "choices": ["東京", "大阪", "京都", "名古屋"], "answer": "ア", "explanation": "…" }
]
```

`question` / `title`、`choices` / `options`、`answer` / `correctIndex`（0〜3）のどちらの名前でも読み込めます。

## 開発メモ

- 収録問題の ID は「検定ID-番号」（例：`itpass-3`）で、並び順から決まります。学習記録はこの ID に結び付くため、問題を追加するときは各セットの**末尾**に追加してください。
- ブラウザに保存するデータのキーは、旧名の名残で `quailq:` から始まります。変えると保存済みのデータが読めなくなるため、そのままにしています。
- 外部ライブラリ（Chart.js・Font Awesome・Firebase）は CDN から、バージョンを固定して読み込んでいます。

### CSS の再生成

`index.html` や `js/` の中で Tailwind のクラスを追加・変更したら、CSS を作り直してコミットしてください（Node.js 18 以上が必要です）。

```bash
npm install
npm run build:css
```

開発中は `npm run watch:css` で、ファイルを保存するたびに自動で再生成できます。GitHub Actions が、`css/tailwind.css` が最新かどうかをプルリクエストごとに確認します。
